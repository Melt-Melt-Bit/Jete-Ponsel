# JT Ponsel

JT Ponsel adalah website toko teknologi untuk menampilkan dan menjelajahi berbagai produk smartphone, earphone, dan aksesori.

## Fitur Utama

- Halaman beranda dengan produk unggulan.
- Katalog produk smartphone dan earphone.
- Detail produk dengan informasi harga dan deskripsi.
- Keranjang belanja sederhana.
- Halaman pembayaran frontend.
- Dashboard admin untuk mengelola produk, harga, gambar, dan visibilitas produk.
- Koleksi gambar produk lokal di `resources/images/phones` dan `resources/images/headphones`.

Website ini dibuat sebagai frontend toko online dan simulasi alur belanja. Proses pembayaran dan transaksi belum terhubung ke sistem nyata.
